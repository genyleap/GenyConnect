# Security Policy

## Supported Versions

GenyConnect is actively maintained and security updates are provided for supported release branches.

| Version | Supported |
|----------|-----------|
| 1.4.x | ✅ |
| 1.3.x | ⚠️ Critical security fixes only |
| < 1.3 | ❌ |

Users are strongly encouraged to update to the latest available release before reporting potential security issues.

---

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues, Discussions, or social media.

If you believe you have discovered a security vulnerability in GenyConnect, please report it privately.

Preferred contact:

- security@genyleap.com

Alternative contact:

- kambiz.ceo@gmail.com

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps required to reproduce it
- Affected platform (Windows, macOS, Linux, Android, iOS)
- GenyConnect version
- Relevant logs or screenshots
- Proof-of-concept code if applicable
- Expected impact

The more information provided, the faster the issue can be investigated.

---

## Response Process

We aim to:

- Acknowledge valid reports within 72 hours
- Perform an initial assessment and severity review
- Request additional information when necessary
- Develop and validate a fix
- Publish a security update when appropriate

Not all reports will result in a security advisory or software update.

---

## Examples of Security Issues

Examples of vulnerabilities that may be considered security issues include:

- Traffic leaks
- DNS leaks
- Sensitive information disclosure
- Insecure update mechanisms
- Authentication or trust validation flaws
- Certificate validation bypasses
- Remote code execution vulnerabilities
- Privilege escalation
- Local file disclosure
- Configuration injection vulnerabilities
- Unsafe handling of credentials, keys, or tokens

---

## Out of Scope

The following are generally not considered security vulnerabilities:

- Feature requests
- UI or UX issues
- Performance problems without security impact
- Reports affecting unsupported versions
- Vulnerabilities introduced by unofficial or modified builds
- Issues caused by third-party software outside the control of GenyConnect
- Theoretical attacks without a practical exploitation path

---

## Responsible Disclosure

Please allow reasonable time for investigation, remediation, and release of a fix before publicly disclosing a vulnerability.
We appreciate responsible disclosure and thank researchers and community members who help improve the security and reliability of GenyConnect.
