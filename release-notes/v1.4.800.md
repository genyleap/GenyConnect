GenyConnect v1.4.800 Released 🚀

A major reliability and networking update focused on faster connections, smarter recovery, and improved platform stability.

✨ Highlights

* Faster connection startup and reduced connection delays
* Automatic recovery from mixed-port and listener failures
* Improved Android VPN lifecycle and runtime readiness detection
* Better update safety and network cleanup after updates
* Improved Linux AppImage compatibility, Wayland support, and Qt/QML runtime handling
* Enhanced profile groups, sorting, and best-profile selection
* Packet-loss aware profile ranking and reliability tracking
* Real route-based latency testing (instead of raw server endpoint ping)
* More accurate speed-test latency measurements through the actual proxy route
* Improved runtime recovery, watchdog behavior, and long-session stability
* Better diagnostics, startup validation, and troubleshooting tools

🛠 Fixes

* Fixed Linux startup failures caused by missing Wayland and KDE/QML runtime dependencies
* Fixed multiple connection-drop scenarios
* Fixed post-update connectivity issues
* Fixed Android runtime state inconsistencies
* Fixed misleading profile ping measurements
* Fixed QML startup issues and UI stability problems
