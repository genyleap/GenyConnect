GenyConnect v1.4.768 Released 🚀

Faster. Smarter. More Reliable.

Version 1.4.768 focuses on platform maturity, runtime reliability, Linux readiness, updater improvements, and a significantly more stable networking experience across desktop and mobile environments.


✨ Highlights

🐧 Linux Support Reaches Production Quality

Linux support has received major improvements and extensive real-world testing.

Improvements include:

* Improved TUN interface initialization
* Better Linux networking integration
* Enhanced route detection and validation
* Improved AppImage runtime environment
* Automatic Linux helper lifecycle management
* Better diagnostics and failure reporting
* Improved compatibility with modern distributions
* ARM64 Linux support improvements
* Better desktop integration and runtime stability

GenyConnect now runs more reliably across Ubuntu, Debian, ARM64 devices, cloud environments, and virtual machines.


📦 AppImage & Packaging Improvements

A significant amount of work has been invested into deployment quality.

Improvements include:

* Improved AppImage runtime compatibility
* Bundled runtime dependency handling
* Improved ICU library portability
* Better Qt runtime integration
* Enhanced self-update packaging
* Improved asset verification
* SHA256 verification workflow improvements
* Better architecture-specific package selection

These changes dramatically reduce compatibility issues across different Linux distributions.


🔄 Smarter Self-Update System

The updater has been redesigned to better understand platform and architecture differences.

Improvements include:

* Platform-aware asset selection
* Architecture-aware package resolution
* Linux ARM64 support improvements
* Linux x86_64 support improvements
* Better fallback handling
* Improved release validation
* Enhanced update diagnostics

GenyConnect now selects the correct update package for:

* Windows x64
* Windows ARM64
* Linux x86_64
* Linux ARM64
* Android ARM64
* Android ARMv7
* macOS Apple Silicon
* macOS Intel


⚡ Runtime Stability Improvements

A large number of runtime edge cases have been addressed.

Improvements include:

* Better connection startup behavior
* Improved tunnel initialization
* Improved session supervision
* Better process lifecycle management
* More reliable helper communication
* Improved cleanup after disconnect
* Reduced startup failures
* Better recovery from runtime errors
* Improved long-running session stability

🌐 Networking Improvements

Networking internals have received multiple refinements.

Improvements include:

* Better TUN configuration validation
* Improved routing consistency
* Better address assignment handling
* Improved IPv4 and IPv6 readiness checks
* Enhanced route verification
* Better network diagnostics
* Improved platform-specific behavior

Diagnosing networking issues is now much easier.

New diagnostic capabilities include:

* Update selection diagnostics
