# GenyConnect v1.4.950

This update refines the desktop and mobile interface, improves Persian and Arabic layouts, and addresses routing, font loading, Linux packaging, and C++ module build issues.

## Interface and accessibility

- Reorganized Settings into searchable Connection, Application, and Help & Support sections, with clearer back and close navigation.
- Refined the Settings drawer, desktop sidebar, profile cards, and import screen with consistent spacing, responsive controls, and wrapping labels and descriptions.
- Corrected RTL alignment and asymmetric mobile insets. Profile names, latency information, and traffic units have more room on narrow screens.
- Introduced a consistent charcoal/slate dark palette with clearer text, borders, selection states, and status chips.
- Separated selected tabs from keyboard focus, improved keyboard navigation, and removed persistent touch hover states and intrusive mobile tooltips.
- Added a wrapping import placeholder and a scrollable editor for long configurations. Corrected the editor height binding loop and recursive layout calculation in the import target section.
- Kept the mobile home, profiles, and import scrolling areas clear of system bars, and improved scrolling to focused Settings controls.
- Registered bundled text and icon fonts before QML initialization and refined font family, weight, and Arabic fallback handling.
- Updated translations across the eight non-English language catalogs.

## Routing and Linux TUN

- Unified legacy routing settings with the ordered rule model so editing, persistence, and generated runtime rules stay consistent.
- Preserved exact executable paths in application rules and improved the application picker, including Windows process enumeration.
- Added clearer handling for enabled rules that the selected runtime cannot apply, instead of silently ignoring them.
- Reworked Linux TUN setup around explicit IPv4/IPv6 policy routes, outbound socket bypass, route-readiness checks, and cleanup on shutdown or startup failure.
- Added a NixOS module for the required system configuration and an explicit iproute2 path for privileged helper execution.

## Packaging and source builds

- Unified AppImage Qt deployment for Linux x86_64 and ARM64, including required Wayland/X11 plugins and their dependencies. Strengthened packaging checks for missing components and unintended host Qt/QML dependencies.
- Added early diagnostics for unsupported CMake generators and documented Ninja setup, fresh build directories, and saved Qt Creator configuration overrides.
- Prefer the module dependency scanner from the active compiler toolchain, including the Android NDK.
- Moved module declarations outside `Q_MOC_RUN` conditionals in six module interfaces to address Clang dependency-scanning failures while retaining Qt-specific type shims.

## Platform notes

- NixOS TUN users must enable the supplied NixOS module or equivalent system settings; installing the package alone is not sufficient. TUN requires an explicit DNS resolver rather than `localhost` or `+local` modes. See the [NixOS setup instructions](https://github.com/genyleap/GenyConnect/blob/v1.4.950/README.md#nix-and-nixos).
- Application/process routing remains dependent on runtime support. The current supported configuration is Windows/Linux with a compatible Xray core; macOS does not advertise this capability. Saved rules remain editable.
- These changes were reviewed statically. Full build, packaging, and cross-platform runtime validation has not been completed as part of this update.
